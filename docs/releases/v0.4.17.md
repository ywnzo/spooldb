# SpoolDB 0.4.17

The client web settings now use five focused pages: This project, Workspace, Sharing, Team, and Advanced. A persistent workspace and shared-project selector makes the scope of each change clear.

Project sharing has per-category effective Shared/Private indicators, with workspace-wide defaults in a separate disclosure. Conversation deletion is separated from ordinary sharing controls. Legacy project connections and local relay administration live under Advanced.

Workspace connection, saved-workspace switching, checkout enrollment and project creation have dedicated controls. Connecting another workspace no longer requires disconnecting first. Settings navigation supports direct links and browser Back/Forward, with responsive Kiln styling and clearer permission and empty states.

Existing capture and sharing policies are preserved. This is a client UI update; upgrading only the relay does not replace an older client interface.

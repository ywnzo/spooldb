# SpoolDB v0.4.6

Native Apple Silicon macOS support for the Codex plugin, including its bundled Bun runtime, MCP server, lifecycle hooks and automatic workspace setup. Install or update SpoolDB from the `ywnzo/spooldb` marketplace, then review the changed hooks once.

This release also handles macOS refusing a process-group termination signal during harness shutdown: the runner falls back to terminating its owned child and preserves the original malformed-output or cancellation result.

The release is gated on a native Apple Silicon MCP and lifecycle-hook smoke test. Intel Macs and Windows are not supported by this bundle. macOS 13 or newer is required.

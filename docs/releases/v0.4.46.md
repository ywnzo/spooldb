# SpoolDB v0.4.46

The CLI, desktop companion, Codex integration, and self-hosted relay now run in Rust. The Cloudflare relay runs Rust compiled to WebAssembly and retains the existing OAuth grant format.

- The existing database formats, repository bindings, invitations, and relay credentials are compatible with the Rust release.
- Managed VPS updates snapshot the relay volume, verify the replacement, and restore the previous installation if validation fails.
- The Codex plugin includes native binaries for Linux x86-64 and Apple Silicon. Changed hooks still go through Codex review.

For a self-hosted upgrade, keep the existing relay data directory or container volume and its credentials. For Cloudflare, use the existing Worker name, Durable Object bindings, OAuth KV namespace, and deployment receipt. See [upgrade and rollback details](../updates.md).

Install SpoolDB directly from Codex:

1. Open **Plugins → Add marketplace**.
2. Enter **`ywnzo/spooldb`**.
3. Install **SpoolDB**.

The plugin prepares its bundled runtime automatically on first use. No manual downloads, archive extraction, separate client installation or JSON configuration are required. Review the named hooks, then connect your workspace in a normal Codex chat.

The release launcher pins the payload checksum and hook fingerprint. A failed download or mismatched hook definition stops setup before the payload runs. Existing packaged installations keep working.

Terminal alternative:

```sh
codex plugin marketplace add ywnzo/spooldb && codex plugin add spooldb@spooldb
```

Linux x86-64 with glibc is currently supported. Workspace and project sharing still require explicit user approval.

# SpoolDB v0.4.5

The Codex plugin now includes native Bun runtimes for Apple Silicon macOS 13+ and Linux x86-64. It selects the correct runtime automatically; no separate SpoolDB or Bun installation is required.

Add `ywnzo/spooldb` in Codex's plugin marketplace settings and install or update SpoolDB. Existing users must review the changed hooks once because this release changes their platform dispatch and integrity checks. Workspace and project sharing still require approval.

Setup and hook verification support the checksum tools included with macOS. A native Apple Silicon CI check builds the plugin, starts its actual MCP server, retrieves tools and checks setup status before a release can publish. Intel Macs and Windows are not included.

Documentation, CI and builds use Bun, and production dependency packaging works offline without a second package manager.

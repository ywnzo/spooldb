# SpoolDB 0.4.13

Managed Docker/Podman VPS relays now support opt-in daily updates:

```sh
sudo spool update enable --target relay
```

Upgrade an existing VPS once with the server installer to gain this command. New installations offer an interactive opt-in prompt. Updates remain disabled by default.

Updates verify official release checksums, build the candidate before downtime, take a stopped-relay memory backup, block client requests during validation, and check HTTPS, the running version and the local administration API. Failed validation restores the previous container, memory, ownership and CLI. Caddy and certificates stay in place. Interrupted transactions can be recovered with `sudo spool update recover`.

Use `sudo spool update status`, `check`, `--yes` or `disable` to control the relay. Logs are available through `journalctl -u spool-relay-update.service`. Backups currently require administrator retention management. See [update documentation](../updates.md).

# SpoolDB v0.4.28

Memory browsing now has persistent category navigation, a compact record list, a focused reader and a visible history control. Archived history selection survives reload and browser navigation.

Settings are grouped into project, workspace and server sections. Search and local model controls have their own Search & memory page; relay health and updates live under Updates & storage. Backup retention is expandable, and the shared-project selector appears only where it applies.

Filtered memory views make one retrieval request instead of fetching unused context first. Recently visited views render cached results while refreshing, and overview polling reuses the context it already fetched. Opening a record directly no longer loads the entire overview first. Cache entries remain in this browser tab, are separated by project and filter, and are cleared after archive or restore.

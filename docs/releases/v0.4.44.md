# SpoolDB v0.4.44

Codex hooks now suggest using SpoolDB when project memory would help. Agents can continue directly or choose to retrieve context and save useful findings and handoffs.

- Session start and prompt submission provide a short hint without contacting the relay.
- Stop and Interrupt take no action. Existing conversation capture follows the project's sharing settings.
- Repository enrollment still requires approval.

Add or refresh the `ywnzo/spooldb` marketplace in Codex, install or update SpoolDB, then review the changed hooks and start a fresh chat.

The release uses GitHub’s supported macOS 15 runner for native Apple Silicon validation.

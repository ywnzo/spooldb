# SpoolDB v0.4.8

The Linux server installer now accepts a domain and runs the relay and Caddy in Docker or Podman. It configures automatic HTTPS and startup after reboot, retains project memory and certificates in named volumes, and prints the initial private owner invitation after verifying HTTPS.

Install a container engine first, point the domain at the VPS, and allow TCP 80/443 in its provider firewall. Run the download installer with `--server`. The advanced native LAN/custom-proxy setup remains available.

Server CLI commands manage the containerized relay. Installer reruns preserve data and restore previous containers if a managed upgrade fails. Existing unmanaged services and container resources are refused. Public certificate issuance requires working DNS and reachable ports; this release does not migrate an existing native relay or redeploy Cloudflare automatically.

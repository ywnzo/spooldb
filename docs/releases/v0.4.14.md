# SpoolDB 0.4.14

Includes the opt-in automatic VPS relay updater introduced in 0.4.13, with an additional interrupted-update recovery fix. Recovery now handles a shutdown between renaming the old container and creating its replacement, and recognizes a completed backup if interruption occurs before its journal entry is written.

After a one-time server installer upgrade, enable scheduled relay updates with:

```sh
sudo spool update enable --target relay
```

Updates verify release checksums, take a cold memory backup, validate the candidate behind a maintenance gate, and restore the prior relay and memory on failure. See [updates](../updates.md) for status, logs, disable and recovery commands.

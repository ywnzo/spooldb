# SpoolDB v0.4.10

Plugin startup now checks the running companion version and capabilities instead of accepting any responding discovery socket. This fixes updated plugins reusing an older service that still rejects Git submodules.

Older plugin-owned companions restart automatically. Recognized Linux user services upgrade using the same project state, with service backups and rollback on failed startup. Concurrent starts share one upgrade lock, and newer compatible companions are never downgraded. Unknown services are left untouched. No workspace migration, sharing changes or hook-review bypass is performed.

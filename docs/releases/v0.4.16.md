# SpoolDB 0.4.16

Automatic VPS retention now also cleans old SpoolDB relay images and application releases. Defaults retain three recent versions for up to 30 days, plus everything needed by the running installation, retained memory backups, manual rollback or interrupted recovery.

All running and stopped container images, the installed CLI, running updater and bind-mounted application releases are protected. Cleanup only targets recognized SpoolDB resources and never uses engine-wide prune or forced image removal. Caddy/base images, unrelated image tags and persistent volumes remain untouched.

New backups record their matching image and application version. Cleanup waits when an older retained backup has no reliable association; the backup retention policy eventually expires it safely.

Automatic cleanup runs with relay update checks and completed update/recovery operations. The server installer also records its previous installation and runs cleanup after successful setup. Preview or run it manually:

```sh
sudo spool update cleanup --dry-run
sudo spool update cleanup
```

Status includes the retention policy and cleanup results. See [updates](../updates.md) for configuration and safety behavior.

# SpoolDB v0.4.40

Nested Git repositories and submodules can now be connected as linked subprojects or separate projects after the user chooses. Linked subprojects retrieve separately authorized parent memory while keeping new records in their own project. Existing connections and memory remain in place.

This release also improves agent guidance for saving useful memory and avoids generic automatic task placeholders. Upgrade the relay before connecting subprojects, then update the Codex plugin and review changed hooks.

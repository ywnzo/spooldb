# SpoolDB v0.4.33

- Enforce a 2,000-character combined budget for new handoffs, with clear validation errors and concise automatic excerpts. Existing history remains readable.
- Add owner-only retrieval usage visibility and persistent daily embedding limits in Settings and `spool workspace usage`. Limits default to unlimited; cached and keyword retrieval remain available when a cap is reached.
- Prioritize interactive embedding queries over queued indexing, with fairness for background work.
- Fix indexing retries, resumable long-record indexing, stale provider replacement and deletion of indexing progress.
- Page exact vector scans to reduce memory use. Synthetic 100,000-vector, 1,024-dimensional testing reduced peak RSS from about 1.7 GiB to 201 MiB; exact scans still take roughly 1.3–1.6 seconds on the benchmark machine.
- Add a release-gated 50-question multilingual retrieval evaluation. The pinned local model achieved 88.1% recall at three results and 69% smaller context by characters in this fixture; two unrelated questions still produced matches. These figures do not establish Cloudflare model quality or VPS latency.

Usage controls apply to the self-hosted relay. Changed plugin hook dependencies may require normal Codex hook review.

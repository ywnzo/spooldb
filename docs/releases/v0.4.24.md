# SpoolDB 0.4.24

Project connection now offers optional analysis of existing local Codex chats into decisions, findings, tasks and handoffs. The choice is saved per checkout. Skip is remembered; accepted analysis stays pending until Codex saves a completion handoff. UI connections and spool init can queue it for the next Codex session.

Approved analysis uses paginated private local capture with a stable ID snapshot. Raw conversation sharing and category policies remain separate. The bundled setup workflow deduplicates existing memory, follows later corrections and distinguishes historical claims from current verification. No unattended relay summarizer or cloud-history access is implied.

The Codex onboarding hook changed, so the updated hooks require review once. Hook trust is never written automatically.

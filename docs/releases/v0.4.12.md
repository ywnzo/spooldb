# SpoolDB v0.4.12

Project admins can preview and delete shared conversations from Codex with `spool_setup action=delete_conversations`, from Project sharing in the web UI, or with `spool project delete-conversations`. Individual captured sessions can be deleted from conversation details or selected through Codex. The confirmation includes the project and message count, and stale previews must be refreshed.

Deletion removes retrievable conversation history while preserving findings, decisions, tasks, handoffs and other projects. Hashed message/session tombstones prevent deleted conversations from being uploaded again by capture clients. Local Codex chats and independent backups are unchanged; previously downloaded copies cannot be recalled. The relay stays online and no automatic rollback copy of deleted text is created by this API.

Native and Cloudflare relays support the operation. Both the client and relay need this release; older relays require a one-time upgrade before remote deletion is available. This release does not deploy to an existing VPS or Cloudflare automatically.

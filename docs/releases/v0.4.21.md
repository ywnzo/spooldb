# SpoolDB 0.4.21

Creating a shared project now remains a create operation even when the Git repository already belongs to another project. Separate projects can reference the same repository without sharing memory. Creation retries return the same newly created project.

Repository discovery returns all matching projects and requires an explicit choice when more than one matches. Codex plugin setup, spool init and web approval distinguish create from join; older ambiguous requests fail instead of silently attaching a checkout. New clients refuse unsupported create semantics on older relays before changing their local connection.

Existing repository associations migrate without changing project rooms, names, grants, sharing policy or memory. Includes the Spool favicon and removal of the header memory label.

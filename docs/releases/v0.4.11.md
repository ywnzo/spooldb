# SpoolDB v0.4.11

New shared-project connections initialize local memory without snapshotting repository files. This prevents large checkouts from failing enrollment with “One atomic batch exceeds the sync page byte limit”. Conversations, decisions, findings, tasks and handoffs still synchronize; source stays in Git, with checkout and submodule references attached to evidence.

Workspace enrollment and project invitations use this mode, including first-run setup. Existing local code-history projects remain unchanged. This release does not automatically transfer historical memory between relays.

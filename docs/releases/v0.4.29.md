# SpoolDB v0.4.29 — security update

This release updates bundled Bun runtimes and container templates to 1.4.4, pins patched native inference dependencies, and rejects stale installed dependencies during packaging. CI now checks dependency advisories and separates publishing credentials from build/test jobs.

Capture now distinguishes ordinary chat JSON from structured system memory and validates complete source pages before mutation. Malformed legacy JSON stays readable as source text. Sharing classification rejects inherited property names, and conversation deletion checks use the same structured-record boundary.

Workspace and invitation routes authenticate before reading request bodies. Cloudflare rechecks membership after asynchronous operations. Semantic retrieval bounds outstanding lookups and project indexing, serializes native inference, and falls back to keyword retrieval under load. Browser memory caches are cleared when a checkout changes its shared connection.

Existing memory is preserved. Runtime and hook dependency changes require normal Codex hook review. Review SECURITY.md for the trust model and remaining operational limits.

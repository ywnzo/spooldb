# SpoolDB v0.4.27

Shared memory retrieval now combines keyword search with local semantic embeddings. The relay downloads pinned, quantized model weights automatically; inference stays on the relay. Settings → Relay lets workspace owners select multilingual or smaller English models, CPU threads, relevance threshold and context budget. Downloads and failures are visible, and keyword retrieval remains available while the index warms up.

Memory cleanup now archives instead of deleting history. Agents can explicitly link findings that resolve or supersede earlier evidence, and archive or restore records with revision checks. Normal retrieval hides archived records, completed tasks and older task revisions. Full records remain available, and the web UI can include archived history and restore records. Concurrent conflicting cleanup remains visible until reconciled.

Agent responses use bounded context cards with source references. The SQLite vector index uses exact scoring; it is not an approximate nearest-neighbor engine. Model caches are excluded from update backups and preserved across rollback.

# SpoolDB 0.4.19

Settings now includes a Relay page for workspace owners on managed Docker/Podman VPS installations. View health, version, free space and maintenance results; check and install updates; toggle daily updates; and change backup, image and application retention limits.

Cleanup requires a fresh preview and preserves current and rollback resources. Maintenance jobs are persistent, serialized and idempotent. Interrupted transactions expose recovery controls while normal writes remain paused.

A narrowly scoped host controller uses a Unix socket mounted read-only into the non-root relay container. It accepts fixed actions and bounded settings, without exposing the container-engine socket. Other workspace roles and project tokens cannot perform maintenance. Existing managed hosts need one upgrade to enable these controls; Cloudflare keeps its existing deployment workflow.

The first published release of these controls also handles older-relay compatibility messages and reports unknown container status explicitly.

First public SpoolDB preview: shared project memory for coding agents and teams.

- Share conversations, decisions, findings, tasks and actionable handoffs across machines.
- Use a self-hosted multi-project relay or deploy to Cloudflare Workers and Durable Objects.
- Connect Codex desktop, terminal and Codex in Zed; expose memory through MCP.
- Control sharing per workspace and project. Code stays in Git, with file and commit references.

## Install

Linux x86-64 with glibc; Git is required for project integration. The installer bundles its runtime.

```sh
curl -fsSL https://github.com/ywnzo/spooldb/releases/latest/download/install.sh -o install-spooldb.sh && sh install-spooldb.sh
```

For a relay server, append `--server`. Setup prints the first owner invitation before any clients connect. For Cloudflare, install the CLI and run `spool deploy cloudflare`.

Downloads include the default Bun installer, a Node alternative, and a self-contained Codex plugin marketplace bundle. Verify downloads against `SHA256SUMS`. These are checksum-verified, unsigned preview builds.

See the [README](https://github.com/ywnzo/spooldb#readme) and [plugin instructions](https://github.com/ywnzo/spooldb/blob/main/docs/codex-plugin.md). Review Codex hooks before enabling them. Cloud skill handoffs are best effort, rather than guaranteed runtime lifecycle capture.

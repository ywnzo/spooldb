# SpoolDB v0.4.37

Shared handoffs now keep one current snapshot even when their task stays private.

- Clients attach a credential-keyed opaque grouping value before removing a private task ID. Private task text and identifiers remain private.
- Relays supersede earlier handoffs in that group while preserving history. Task promotion to shared memory keeps the same handoff continuity.
- Older taskless handoffs with a session identity can update within the same author, session and project. Unrelated tasks, authors and projects remain separate.
- Regression coverage includes private tasks, multiple tasks in one chat, promotion, unchanged handoffs and isolation.

The six confirmed duplicate GEREQ_PLATFORM namespace-fix handoffs were consolidated separately; all original history and referenced findings were preserved. This release does not automatically merge unrelated historical handoffs by textual similarity.

Update clients as well as relays to use opaque task grouping. Review changed hooks if Codex requests it and start a fresh chat after plugin updates.

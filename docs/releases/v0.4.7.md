# SpoolDB v0.4.7

Git submodules no longer block parent project capture. Handoffs and findings include nested Gitlink and checkout references; retrieval detects changed, dirty and uninitialized submodules without uploading their source code. Direct submodule connections keep separate sharing approval.

Opt-in daily updates are available from Codex setup or `spool update enable`. Plugin updates use Codex on Linux and Apple Silicon, wait for active sessions to end and retain hook-review requirements. The standalone Linux client updater verifies download checksums, preserves connections and restores the previous application on installation failure.

Upgrade shared relays before clients send submodule metadata. Automatic updates do not deploy Cloudflare Workers or self-hosted relay servers.

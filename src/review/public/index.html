Usage & limits

Connect as workspace owner to view usage.

Zero means unlimited. Resets at midnight UTC. Counts attempted external requests, including tests and retries; characters approximate usage, not provider tokens or a currency spending limit. Cached and keyword retrieval remain available when capped.

Archived memory

Advanced: local relay administration

One relay can host many projects. Create a project, then send a separate invite link to each teammate. Links expire after 24 hours and can be used once.

The host connection specifies its HTTPS address and certificate when needed. Teammates paste the invite into the interactive installer or open it after installation. No project access is granted by the UI address alone.
